# PinkClub-FL

主要機能に絞って軽量化したFANZAアフィリエイト商品サイトです。

## 特徴

- PHP・MySQL（MariaDB）・JavaScriptで動作
- フレームワーク不使用
- PC・スマートフォン対応
- WordPress風の管理画面
- 商品情報APIだけを使用
- cronによる商品自動更新
- 内蔵アクセス解析
- 商品ランキング
- 公開ページキャッシュ

## 通常版から外した機能

- 「気分で探す」
- 最近見た作品
- 女優API
- ジャンルAPI
- シリーズAPI
- FloorList API
- 女優プロフィールと女優画像の保存
- 女優プロフィールなどの商品以外の個別詳細ページ
- 商品以外のランキング
- 掲載削除依頼機能

商品カードと商品詳細ページのサンプル画像・サンプル動画は残しています。サンプル画像がAPIに存在しない商品では、商品カードのサンプル画像ボタンを無効表示します。パッケージ画像はサンプル画像として扱いません。

## 検索

女優・ジャンル・メーカー・レーベル・シリーズ・監督・作者の名称リンクは、すべて共通の商品検索結果へ移動します。

女優・ジャンル・メーカー・レーベル・シリーズは、商品APIから保存した名称だけの一覧を表示します。一覧の名称を選ぶと共通の商品検索結果へ移動します。

女優プロフィールは保存しません。商品情報APIに含まれる女優名は、商品との関連情報として`item_actresses`へ保存します。

検索は巨大な`raw_json`全体を走査せず、商品タイトル・商品IDと商品APIから保存した関連名を検索します。

## ランキング

商品ランキングだけを残しています。

- 本日
- 週間
- 月間
- 年間

商品ランキングは30分キャッシュし、古いキャッシュがある場合は表示を維持したまま更新します。

## 内蔵アクセス解析

内蔵アクセス解析は通常版と同様に残しています。

- PV・UU
- リファラー
- クリック先
- 検索エンジン
- 検索ワード
- 滞在時間

ブラウザーからの同一ページPVは短時間の重複送信を抑止し、管理画面・bot・外部サイトから直接送信された計測POSTを一般閲覧として数えないようにしています。

## セットアップ

1. サーバーへファイル一式をアップロードします。
2. ブラウザで`/public/setup_check.php`を開きます。
3. DBホスト名・ポート・DB名・ユーザー名・パスワードを保存します。
4. 「セットアップを実行する」を押します。
5. `/public/login0718.php`から管理画面へログインします。

新規セットアップでは管理者名`admin`とランダムな初期パスワードを作成します。初期パスワードはセットアップ直後のログイン画面に一度だけ表示し、ログへ平文保存しません。初回ログイン後は「個人設定」でログインID・再設定用メールアドレス・12文字以上の新しいパスワードへ変更してください。変更後は`admin` / `password`を再利用できません。

## API設定

管理画面の「商品情報API設定」で次を保存します。

- APIID
- アフィリエイトID

PinkClub-FLは商品情報API（ItemList）だけを呼び出します。ジャンル・女優・シリーズなどは、商品情報APIの`iteminfo`に含まれる情報から保存します。

## 自動更新

自動更新はcron専用です。公開ページや管理画面へのアクセスでは商品同期を開始しません。

```bash
php /path/to/PinkClub-FL/scripts/auto_import.php
```

推奨cron間隔は10分です。実際の商品取得間隔と取得件数は管理画面から設定できます。

## 固定URL

- 公開トップ：`/`
- 管理ログイン：`/public/login0718.php`
- 管理トップ：`/admin/index.php`
- セットアップ確認：`/public/setup_check.php`
- 商品API設定：`/admin/api_items.php`
- 自動設定：`/admin/api_auto.php`
- アクセス解析：`/admin/analytics.php`

## データ保存方針

- 商品は`content_id`を一意キーとしてupsertします。
- APIレスポンスは`items.raw_json`にも保存します。
- 商品に含まれる関連名は、各`item_*`テーブルへ保存します。
- 女優マスタへのプロフィール保存や女優APIによる更新は行いません。
- APIキーやDBパスワードはGitへ保存しません。

## 表示速度

- 不要なAPI同期と個別詳細ページを廃止
- サンプル画像の有無は保存済みAPIレスポンスだけで判定
- 公開ページキャッシュ
- 商品ランキングキャッシュ
- 検索用関連テーブル索引
- 画像遅延読み込み
- CSS・JavaScript・画像など静的ファイルの長期キャッシュと圧縮
- cron専用の商品同期

## 開発方針

- 既存デザインを維持する
- 不要な全面リファクタリングを行わない
- 作業ブランチとDraft PRを使用する
- 確認前に`main`へマージしない
- 外部画像や動画の利用条件を守る
